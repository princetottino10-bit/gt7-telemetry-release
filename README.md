# GT7テレメトリ

PS5のグランツーリスモ7の走行データをPCで記録して、周ごとのレポートを作るツールです。走っている間は、PCやスマホの画面に「次のコーナーの目標速度」が出ます（ずんだもんの読み上げもあります）。

## ダウンロード

**[GT7-Telemetry.zip をダウンロード](https://github.com/princetottino10-bit/gt7-telemetry-release/raw/main/GT7-Telemetry.zip)**（アカウント不要）

## 必要なもの

- Windows 10 / 11 のPC
- PS5とPCが**同じWi-Fi／ルーター**に繋がっていること（PS5側の設定変更はありません）
- 最初の1回だけインターネット接続（必要なものを自動で取ってきます）

Pythonやほかのソフトを自分で入れる必要はありません。

## インストール（最初の1回だけ）

1. ZIPを好きな場所（デスクトップやドキュメントなど）に**展開**します。展開せずに中のファイルを開くと動きません。
2. 展開したフォルダの **「はじめに実行してください.bat」** をダブルクリックします。2〜3分で終わります。
3. デスクトップに2つのアイコンができます。以後はこの2つしか使いません。
   - **GT7テレメトリ**: 記録する
   - **GT7テレメトリ（記録一覧）**: 過去の記録を見る

フォルダを別の場所に移したときだけ、もう一度「はじめに実行してください.bat」を実行してください。

## 初めて記録するとき

Windowsの確認画面が2つ出ることがあります。どちらも許可してください。

- **「アクセスを許可する」**（Windowsセキュリティの警告）: PS5からのデータを受け取るためです。
- **「このアプリがデバイスに変更を加えることを許可しますか？」→「はい」**: スマホからライブ画面を開けるようにするためです。「いいえ」を押しても、あとでライブ画面の「スマホで見る」から許可できます。

## 走るたびの流れ

1. GT7でコースに出る
2. デスクトップの **GT7テレメトリ** を押す（ブラウザにライブ画面が開きます）
3. 走る。走り出して400mほどでコースが判別され、「次」の枠に次のコーナーの目標速度が出ます（そのコースのレポートが今週あるとき）
4. コースを降りる（またはライブ画面の「記録を終了してレポートへ」を押す）と、レポートが開きます

## 使い方を忘れたら

ライブ画面の上と、レポート右下のバーにある **「使い方」** を押すと、説明書（マニュアル）が開きます。フォルダの中の「マニュアル.html」も同じものです。

## 更新

新しい版が出ると、ライブ画面の上に **「新しい版があります」** と出ます。押すとZIPが落ちてくるので、**今のフォルダに上書きで展開**してください。走行記録（sessions フォルダ）は消えません。記録のウィンドウは閉じてから展開してください。

## うまくいかないとき

- **データが来ない**: PS5とPCが同じルーターに繋がっているか、GT7でコース上にいるか（メニュー画面ではデータが流れません）を確認してください。
- **スマホで開けない**: スマホが同じWi-Fiに繋がっているか確認して、ライブ画面の「スマホで見る」にオレンジ色の「スマホから開けるようにする」が出ていたら押してください（PCに確認画面が出るので「はい」）。
- **「新しい版があります」が消えない**: 記録のウィンドウを一度閉じて、アイコンから起動し直してください。
